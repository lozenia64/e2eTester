# 텔레그램 봇 설정

폰의 텔레그램에서 본인 예약을 바로 실행합니다. 봇 하나를 모두가 함께 쓰고, 각 사용자가 자기 계정을 직접 연결합니다. PC가 텔레그램 서버로 나가는 연결만 쓰므로 공개 URL, 포트 개방, 비용이 필요 없고 폰이 PC와 같은 네트워크에 없어도 됩니다. 서버 env: [INSTALL.md](INSTALL.md). 행동 명세: [SPEC-SCHED-004](specs/scheduling/04-telegram-bot.md).

## 관리자: 봇 준비 (최초 1회)

1. 텔레그램에서 `@BotFather`를 검색합니다. 이름 옆에 파란 인증 표시가 있는 계정을 고릅니다.
2. `/newbot`을 보내고 표시 이름과 `bot`으로 끝나는 사용자명을 정합니다. 답장의 `123456789:AA...` 값이 **봇 토큰**입니다. 비밀번호처럼 다룹니다.
3. 같은 대화에서 다음 두 가지를 설정합니다.
   - `/setjoingroups` → 봇 선택 → `Disable`: 그룹 초대를 막습니다.
   - `/setcommands` → 봇 선택 → `run - 예약 점검 실행` 전송: 메뉴에 `/run`이 나타납니다.
4. 프로젝트의 `.env`에 토큰을 넣고 앱을 재시작합니다. 로그에 `텔레그램 봇 시작`이 나오면 켜진 것입니다.

   ```env
   E2E_TELEGRAM_BOT_TOKEN=123456789:AA...
   ```

## 사용자: 내 계정 연결 (사람마다 1회)

1. 웹에 로그인하고 왼쪽 아래 `텔레그램 연결`을 엽니다.
2. `연결 코드 받기`를 누릅니다.
3. 폰의 텔레그램에서 화면에 나온 봇을 찾아 `시작`을 누릅니다.
4. 화면에 나온 `/link 코드`를 그대로 보냅니다. 코드는 10분 동안 한 번만 쓸 수 있습니다.
5. `계정에 연결했습니다` 답장이 오면 끝입니다. 연결 정보는 사용자별로 DB에 저장됩니다.

연결을 끊으려면 같은 화면에서 `연결 해제`를 누릅니다.
미사용 연결 코드와 확인 카드도 함께 만료됩니다. 연결 해제·계정 비활성화·예약 권한 회수 후에는 기존 실행 알림과 인증 요청도 다음 확인 주기에 정리됩니다.

## 점검 실행

1. 봇 채팅에서 `/run`을 보냅니다. 예약 관리 화면과 같은 범위가 보입니다. 일반 사용자는 본인이 만든 예약, 관리자는 전체입니다.
2. 목록에서 예약을 누릅니다.
3. 내용을 확인하고 60초 안에 `실행`을 누릅니다.
4. 메시지 하나에서 진행 상태가 바뀌고, 끝나면 결과가 새 메시지로 옵니다. 실행 기록에는 내 이름으로 남습니다.

인증번호가 필요하면 봇이 물어봅니다. 그 메시지에 **답장**으로 번호를 보내면 전달 후 채팅에서 지웁니다. SMS 중계기로 먼저 들어오면 요청 메시지가 사라지므로 입력할 필요가 없습니다.
새 인증 요청이 생기면 반드시 새 메시지에 답장합니다. 이전 실행이나 이전 인증 단계의 요청에 보낸 답장은 전달하지 않습니다.

## 지켜야 할 것

- **PC가 깨어 있어야 합니다.** 절전이나 종료 상태면 봇은 실행도 답장도 못 해서 무응답으로 보입니다. Windows 전원 설정에서 전원 연결 시 절전을 끕니다.
- **봇 채팅은 E2E 암호화가 아닙니다.** 봇은 예약 이름, 시스템 이름, 상태, 건수만 보냅니다. 채팅에 비밀번호나 개인정보를 적지 않습니다. 실패 원인과 스크린샷은 대시보드에서 봅니다.
- **연결 코드와 토큰은 공유하지 않습니다.** 연결 코드를 보낸 텔레그램 계정이 내 예약을 실행할 수 있게 됩니다.
- **토큰은 한 곳에서만 씁니다.** 같은 토큰으로 두 PC에서 앱을 띄우면 서로 충돌합니다.

## 문제 해결

| 증상 | 원인과 조치 |
| --- | --- |
| 아무 응답이 없음 | PC 절전이나 앱 종료 상태이거나, 계정이 아직 연결되지 않았습니다. 웹에서 연결 상태를 확인합니다. 비활성 사용자에게도 답하지 않습니다 |
| 웹에 `텔레그램 봇이 설정되지 않았습니다` | `.env`의 `E2E_TELEGRAM_BOT_TOKEN`을 확인하고 앱을 재시작합니다 |
| `만료되었거나 잘못된 코드입니다` | 웹에서 새 코드를 받습니다. 앱을 재시작해도 코드는 사라집니다 |
| `N분 전 메시지라 처리하지 않았습니다` | PC가 깨어나며 2분 넘게 지난 메시지를 받았습니다. 다시 보냅니다 |
| `만료된 버튼입니다` | 60초가 지났거나 앱이 재시작됐거나 새 카드가 열렸습니다. `/run`부터 다시 합니다 |
| `내용을 확인한 뒤 다시 눌러 주세요` | 카드가 뜬 직후의 탭은 더블탭으로 보고 무시합니다. 다시 누릅니다 |
| 로그에 `텔레그램 폴링 실패`와 `409` | 같은 토큰을 쓰는 다른 프로세스가 있습니다. 하나만 남깁니다 |
| `409`와 `webhook is active` | 다른 서비스에 연결했던 봇입니다. `getWebhookInfo`로 URL을 확인합니다. 안 쓰는 URL이면 `deleteWebhook`으로 지우고, 쓰는 URL이면 봇을 새로 만듭니다 |
| 로그에 `텔레그램 폴링 실패`와 `ConnectError` | PC가 `api.telegram.org`에 닿지 못합니다. 네트워크가 복구되면 자동으로 재연결합니다. 공개 프록시로 우회하지 않습니다 |

토큰이 유출되면 BotFather의 `/token`으로 새 토큰을 발급받아 `.env`를 바꾸고 앱을 재시작합니다. 계정 연결은 DB에 있어서 그대로 유지됩니다.
