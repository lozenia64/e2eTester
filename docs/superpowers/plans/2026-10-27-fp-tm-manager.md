# FP 계약서 분기 및 관리자 확인

사용자 요구: `sales02.do`, `sales02_tm1.do` 모두 본인인증 성공으로 처리한다. TM 화면에서는 입력 프리셋의 관리자사번을 확인한 뒤 기존 서류 점검을 계속한다.

기존 manifest 기반 폼과 프리셋 저장을 사용한다. 관리자사번은 선택 입력이며 TM 진입 시 7자리 숫자를 요구한다. 일반 경로는 기존 프리셋으로도 실행할 수 있다. 사용자 제공 사번을 소스 기본값으로 넣지 않는다.

- [x] 실제 브라우저 DOM 기반 회귀 테스트로 두 경로·관리자 확인·누락/오류를 검증하고 실패를 확인한다(초기 9실패·2통과).
- [x] 공통 계약서 경로 판정, 런타임·Flow 전달, TM 관리자 확인, 완료 문구 호환을 구현한다.
- [x] 프리셋 저장 테스트와 manifest·시나리오·Spec을 갱신한다.
- [x] 관련 테스트·문서 검사와 전체 CI 게이트를 실행한다(16개 게이트 통과).
- [x] Playwright MCP로 관리자 확인 이후 OZ 및 최종 인증 흐름을 점검한다. 관리자 확인·서약서 전자서명 성공 후 다른 미제출 양식 2건으로 2차 인증 진입이 차단됨을 확인했다.

검증: 관련 테스트 25개 통과. 별도 코드 리뷰에서 중요한 결함 없음. 관리자 확인 순서·런타임/Flow 전달·두 계약서 경로의 OTP 제출 테스트를 보강했다.
