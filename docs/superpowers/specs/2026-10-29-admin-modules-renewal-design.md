# 관리자 모듈 설정 리뉴얼 설계

2026-10-29 사용자가 `research/admin-modules-renewal-mockup.html`의 구성과 상단 높이 축소 수정을 승인하고 제품 적용을 요청했다.

## 승인한 구성

기존 관리자 셸을 유지하고 밝은 바탕·인디고 포인트로 통일한다. 좌측 시스템 탐색/검색, 우측 선택한 시스템의 모듈 표/검색/전체·별도 설정·변경됨 필터, 10/15개 단위 페이지 이동, 변경 건수·취소·저장 바를 제공한다. 모듈 이름 아래 ID, 기본 시간·적용 시간·분/초 환산·설정 상태를 표시한다. 상단은 간결하게 하고 시스템/편집 영역 높이를 최소 620px로 확보한다. 낮은 화면에서는 페이지 스크롤을 허용하며 내부 목록/표 스크롤로 항목 증가를 수용한다. 좁은 화면은 시스템 목록 위/편집 표 아래로 배치한다.

## 접근법

접기·펼치기는 펼친 수만큼 길어지고, 가로 탭은 시스템 증가 시 탐색이 어려워 사용자가 시스템 탐색+단일 편집안을 승인했다. 기존 API를 유지하고 Jinja 마크업 + Vite TypeScript/CSS 전용 엔트리로 구현한다. 목업의 확장 예시 버튼·예시 데이터·셸은 제품에 넣지 않는다.

## 동작과 제약

GET `/api/admin/module-settings`와 PUT `/api/admin/module-settings/systems/{system_code}`를 사용한다. 변경한 모듈만 전송한다. API 정책과 동일하게 0 이상의 안전한 정수를 허용하고 소수·음수·빈 값은 저장하지 않는다. ‘별도 설정’은 기본 시간과의 차이가 아닌 `is_overridden`으로 판정한다. ‘변경 취소’는 미저장 초안을 마지막 저장값으로 되돌리는 기능이며 DB override 삭제가 아니다.

모듈 검색/필터/페이지 이동은 초안을 보존한다. 다른 시스템 선택 및 새로 불러오기는 미저장 변경을 확인한 뒤 폐기한다. 조회 실패는 재시도, 저장 실패는 초안 유지, HTTP 200의 `ok:false` 일부 저장은 `saved` 항목만 저장값으로 반영하고 실패 항목을 편집 상태로 유지한다. 처리 중 입력·선택·페이지 전환을 잠근다. 입력 포커스와 스크롤을 유지하며 사용자 문자열은 이스케이프한다.

## 검증

검색/필터/페이지와 숨겨진 초안 저장, 변경 취소·전환 확인, 입력 유효성, 중복 요청, 일부 저장/HTTP·네트워크 오류·재시도, 빈 데이터·HTML문자, 390px 모바일/낮은 데스크톱 높이, 키보드 접근을 확인한다. 브라우저 검증은 읽기와 로컬 초안 변경까지만 수행하고 실제 설정 저장은 하지 않는다.
