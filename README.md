# 점검 대시보드

사내 웹사이트를 Playwright로 자동 점검하는 내부 도구입니다. 대시보드에서 실행을 누르면 점검 PC의 브라우저가 열리고, 단계별 로그·스크린샷이 남습니다.

## 빠른 시작

1. 담당자에게 접속 URL·계정을 받습니다.
2. **점검 실행**에서 시스템·모듈·인증 정보를 고르고 실행합니다.
3. **일간 점검 현황**·**점검 이력**에서 결과를 확인합니다.

휴대폰 인증 구간은 `WAITING_INPUT` 으로 멈추며, OTP 입력 후 재개됩니다.

## 주요 메뉴

| 메뉴 | 용도 |
| --- | --- |
| 일간 점검 현황 | 오늘 시스템·모듈 상태 |
| 점검 실행 | 즉시 Run / 전체 순차 점검(SUITE) |
| 점검 이력 | 과거 Run 조회 |
| 프리셋 관리 | 인증·모듈 조합 저장 |
| 예약 관리 | cron·모바일 즉시 실행 URL |
| 이상징후 인박스 | `ANOMALY` 건 모음 |
| 자가 치유 센터 | 셀렉터 자동 복구·패치 승인 |
| 관리자 | 사용자·통계·전체 이력 |

## 결과 해석

| 상태 | 의미 |
| --- | --- |
| 정상 | 흐름이 기대대로 완료 |
| 이상징후 | 점검은 끝났으나 사이트 이상 발견 → 담당 부서 알림 |
| 점검실패 | 도구·환경 오류 → 운영 담당 알림 |
| 건너뜀 / 취소 / 입력 대기 | 선택 제외·중단·OTP 대기 |

## 점검 대상 (6시스템)

HOM·MHM(대표홈), FP(위촉서류), HRP(현장출동), HWTC(연수원), CHBOT(챗봇). SUITE 는 시스템별 프리셋 지정 후 순차 실행.

## FAQ

**고객용 서비스인가요?** 아니요, 사내 품질 점검용입니다.

**웹만 열면 되나요?** 아니요, 브라우저 자동화는 점검 PC에서 실행됩니다.

**예약이 안 돌았어요.** 예약 관리에서 상태 확인 후 담당자에게 문의하세요.
