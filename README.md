# E2E Control Deck (점검 대시보드) 사용 가이드

사내 주요 웹사이트(대표홈페이지·위촉서류·현장출동·연수원·챗봇)가 정상 동작하는지 실제 브라우저로 자동 점검하고, 단계별 화면 스크린샷과 기록을 남기는 사내 품질 점검 도구입니다.

---

## 1. 처음 시작하기 (5분 따라하기)

### ① 로그인과 첫 화면 (`대시보드`)
1. 담당자에게 전달받은 **접속 주소(URL)** 와 **이메일·초기 비밀번호**로 로그인합니다.
2. 로그인 후 첫 화면인 **`대시보드`** 에서 오늘의 전체 점검 상태(진행 링, 요약 카드 4장, 시스템별 진행 막대, 최근 활동)를 한눈에 볼 수 있습니다.
   - 시스템 행의 빈 곳이나 이름을 누르면 오른쪽에 **시스템 상세 창**이 열리고, 각 모듈 칸을 누르면 해당 점검의 상세 기록 화면으로 이동합니다.
   - 첫 로그인 후에는 왼쪽 아래 **`비밀번호 변경`** 에서 비밀번호를 변경해 주세요.

> **참고 (관리자 계정으로 로그인한 경우):** 관리자(`admin`) 계정은 로그인 시 일반 대시보드 대신 **`관리자 모드` (`/admin`)** 화면으로 바로 이동합니다. 직접 점검을 실행하거나 일반 대시보드를 보려면 일반 사용자 계정을 사용하세요.

### ② 내 점검 세트 먼저 저장하기 (`프리셋 관리`)
점검할 때마다 이름·생년월일·휴대폰 번호를 반복 입력하지 않도록 **내 점검 세트(프리셋)** 를 먼저 만들어 두는 것이 좋습니다. 특히 **전체 순차 점검(`SUITE`)** 과 **`예약 관리`** 를 쓰려면 프리셋이 꼭 필요합니다.

1. 왼쪽 메뉴에서 **`프리셋 관리`** 를 누릅니다.
2. 시스템을 고르고 세트 이름(예: `내 휴대폰 로그인 세트`), 인증 방식(휴대폰/카카오 등), 본인인증 정보, 점검할 모듈을 선택한 뒤 저장합니다.
3. 저장한 프리셋은 본인에게만 보이며 암호화되어 안전하게 보관됩니다.

### ③ 점검 실행하기 (`점검 실행`)
1. 왼쪽 메뉴에서 **`점검 실행`** 을 누릅니다.
2. 왼쪽 목록에서 점검할 대상을 고릅니다:
   - **개별 시스템 (`HOM`, `MHM`, `FP`, `HRP`, `HWTC`, `CHBOT`)**: 저장해 둔 프리셋 칩을 누르거나 직접 정보를 입력하고, 상단 모듈 그래프에서 원하는 단계를 체크한 뒤 **실행**을 누릅니다.
   - **전체 순차 점검 (`SUITE`)**: 여러 시스템을 순서대로 한 번에 점검합니다. 포함할 시스템을 고르고 각 시스템에 사용할 프리셋을 지정한 뒤 **실행**을 누릅니다.
3. 실행이 시작되면 상세 화면으로 이동하며, 각 단계가 진행되는 모습과 실시간 로그·스크린샷을 바로 확인할 수 있습니다.

### ④ 본인인증(휴대폰 OTP · 카카오톡) 처리하기
로그인이 필요한 점검 단계에서는 본인인증이 진행됩니다:

- **휴대폰 인증**: 인증번호가 발송되면 점검 상태가 **`입력 대기`** 로 멈추고 화면에 입력창이 나타납니다. 휴대폰 문자로 받은 인증번호를 입력해 제출하면 점검이 이어서 진행됩니다. (안드로이드 SMS 자동입력 중계기가 켜져 있다면 직접 입력하지 않아도 자동으로 넘어갑니다.)
- **카카오톡 인증**: 스마트폰 카카오톡으로 인증 요청 메시지가 옵니다. 카카오톡에서 인증을 완료하고 잠시 기다리면(약 30초 간격 자동 확인) 화면의 `인증완료` 버튼을 스스로 누르고 다음 단계로 넘어갑니다.

## 2. 왼쪽 메뉴 안내

| 메뉴 이름 | 무엇을 하는 곳인가요? |
| --- | --- |
| **대시보드** | 오늘 내가 담당하는 시스템·모듈의 점검 통과율, 주의 항목, 최근 활동을 한눈에 확인합니다. (상단 주의 안내의 `전체 보기`를 누르면 **이상징후 인박스**로 이동해 담당자 지정·조치 상태를 기록할 수 있습니다.) |
| **점검 실행** | 단일 시스템 점검 또는 전체 순차 점검(`SUITE`)을 즉시 실행합니다. |
| **Run 이력** | 최근 7일간의 시간대별 점검 커버리지 격자와 과거 점검 기록을 날짜·시스템별로 찾아봅니다. |
| **프리셋 관리** | 자주 쓰는 본인인증 정보와 점검 모듈 조합을 내 점검 세트로 저장·수정·삭제합니다. |
| **예약 관리** | 원하는 요일·시각에 점검이 자동으로 돌도록 예약하고, 주간 캘린더·성공률·모바일 즉시 실행 링크를 관리합니다. |
| **자가 치유 센터** | 웹사이트 화면 구조가 조금 바뀌었을 때 도구가 스스로 복구한 내역을 보고, 코드 수정 패치를 승인·반려합니다. |
| **비밀번호 변경 / 텔레그램 연결** *(좌측 하단)* | 내 계정 비밀번호를 바꾸거나, 스마트폰 텔레그램 봇과 내 계정을 연결합니다. |
| **상황판 (`/wall`)** | 로그인 없이 사무실 벽면 모니터나 TV에 띄워 두는 전사 실시간 점검 현황판입니다. |
| **관리자 모드 (`/admin`)** *(관리자 전용)* | 월간 추정 절감 시간·성과 대시보드, 전체 Run 보드(트리맵·CSV 내보내기), 사용자 계정·시스템 권한 관리, 모듈별 수동 소요 시간 설정을 관리합니다. |

## 3. 점검 결과 배지 읽는 법

점검이 끝나면 각 시스템과 모듈에 아래 상태 배지가 표시됩니다. **실제 웹사이트 문제(`이상징후`)** 와 **점검 도구/네트워크 문제(`점검실패`)** 를 구분해 대응합니다.

| 화면 배지 | 의미 | 어떻게 해야 하나요? |
| --- | --- | --- |
| **정상** | 모든 단계가 기대한 대로 통과했습니다. | 별도 조치가 필요 없습니다. (`⟳` 또는 **`자동 복구됨`** 표시가 함께 있으면 일시적 오류를 스스로 재시도해 통과한 것입니다.) |
| **이상징후** | 점검 절차를 끝까지 수행했으나 **실제 대상 웹사이트에서 오류나 비정상 화면**이 발견되었습니다. | 상세 화면의 **스크린샷·AI 실패 분석 요약**을 확인하고 해당 웹사이트 담당 부서에 공유합니다. |
| **점검실패** | 대상 웹사이트 문제가 아니라, 네트워크 지연·브라우저 종료·인증 시간 초과 등 **점검 도구나 환경 문제**로 중단되었습니다. | 상세 화면의 **`실패 지점부터 재실행`** 또는 **`다시 실행`** 을 눌러 재시도하거나 점검 환경 운영 담당자에게 문의합니다. |
| **입력 대기** | 휴대폰 SMS 인증번호 입력을 기다리는 중입니다. | 화면(또는 텔레그램·모바일 링크)에 인증번호를 입력해 주세요. |
| **실행 중 / 대기** | 현재 브라우저에서 점검이 돌고 있거나 앞선 점검이 끝나기를 기다리는 중입니다. | 완료될 때까지 잠시 기다려 주세요. |
| **차단** | 앞 단계 모듈(예: `로그인`)이 통과하지 못해, 그다음 단계(예: `계약조회`)를 실행하지 않고 건너뛰었습니다. | 앞 단계가 왜 실패했는지 먼저 확인한 뒤 재실행하세요. |
| **제외** | 이번 점검을 시작할 때 사용자가 선택하지 않아 실행하지 않은 모듈입니다. | 정상적인 건너뜀입니다. |
| **취소** | 사용자가 직접 중단했거나 프로그램 재시작으로 취소된 점검입니다. | 필요하면 새로 점검을 실행하세요. |

## 4. 자동 예약 및 스마트폰에서 실행하기

### ① 정기 예약 걸어두기 (`예약 관리`)
- **`예약 관리`** 에서 시스템(또는 `SUITE`), 사용할 프리셋, 실행할 요일·시각을 지정해 두면 매일/매주 정해진 시간에 자동으로 점검이 실행됩니다.
- 휴일이나 시스템 정기점검 날에는 예약을 삭제하지 않고 **`일시정지`** 기능으로 특정 시각까지 잠시 멈춰 둘 수 있습니다.
- 프리셋에 연결된 예약은 나중에 **`프리셋 관리`** 에서 내 인증 정보만 수정해도 다음 예약 실행부터 바뀐 정보가 자동 반영됩니다.

### ② 자리 비웠을 때 스마트폰으로 실행하기 (2가지 방법)
PC 앞에 없을 때도 스마트폰으로 내 예약을 즉시 실행하고 휴대폰 인증번호(OTP)까지 입력할 수 있습니다.

1. **텔레그램 봇으로 실행하기 (추천)**
   - 웹 화면 왼쪽 아래 **`텔레그램 연결`** 에서 1회용 연결 코드를 받아 스마트폰 텔레그램 봇에 보내 계정을 연결합니다.
   - 이후 언제든 텔레그램 채팅방에서 `/run`을 보내 내 예약 목록을 보고 터치로 실행할 수 있으며, 인증번호 요청이 오면 그 메시지에 **답장**으로 번호를 보내 이어갈 수 있습니다.
   - 자세한 설정·사용법: **[텔레그램 봇 가이드 (`docs/telegram_bot.md`)](docs/telegram_bot.md)**
2. **모바일 즉시 점검 링크 (`/m/...`)로 실행하기**
   - **`예약 관리`** 에서 각 예약의 **모바일 즉시 실행 URL**을 복사해 스마트폰 브라우저 즐겨찾기나 홈 화면에 추가해 둡니다.
   - 별도 로그인 없이 링크만 열면 바로 점검을 시작하고 진행 상태 확인·인증번호 입력까지 할 수 있습니다. (주소 자체가 열쇠이므로 외부에 공유하지 마세요.)

## 6. 자주 묻는 질문 (FAQ)

**Q. 내 PC에서 웹 화면만 열면 내 PC의 브라우저가 움직이나요?**  
A. 아니요. 실제 브라우저 자동화는 **점검 서버(점검 전용 PC)** 에서 실행되며, 사용자는 웹 대시보드나 스마트폰을 통해 명령을 내리고 실시간 로그·스크린샷 결과를 받아봅니다.

**Q. 하위 모듈(예: `계약조회`)만 체크하고 실행했더니 실행이 안 돼요.**  
A. 로그인이 필요한 모듈은 앞선 `메인 접속`·`로그인` 모듈과 함께 선택해야 실행할 수 있습니다. 실행 화면의 모듈 그래프에서 연결된 선행 모듈을 함께 체크하거나, 이미 돌았던 점검의 상세 화면에서 **`실패 지점부터 재실행`** 기능을 사용해 주세요.

**Q. 예약해 둔 시각이 지났는데 점검이 돌지 않았어요.**  
A. 예약 점검과 텔레그램 봇은 **점검 전용 PC가 켜져 있고 절전 모드가 아닐 때** 동작합니다. 또한 같은 예약의 이전 실행이 아직 진행 중이면 중복 실행을 막기 위해 해당 회차를 건너뛰고 `예약 관리` 보드에 `누락(missed)`으로 표시합니다.

**Q. 휴대폰 번호나 인증 정보가 바뀌었는데 예약을 다 새로 만들어야 하나요?**  
A. 프리셋을 연결해 만든 예약이라면 **`프리셋 관리`** 에서 해당 프리셋의 정보만 수정하면 됩니다. 연결된 모든 예약과 `SUITE`에 자동으로 새 정보가 적용됩니다.
